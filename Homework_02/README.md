# CS 6220 – Homework 2

Implements a synthetic data generator, linear regression (via the normal
equation), and a regression tree (recursive binary splits) from scratch,
then evaluates both on linear and cubic true functions with varying noise
levels and schemas.

## Contents
- `CS6220_DM_Homework02_Rutuja.ipynb` — data generator, linear regression,
  regression tree implementations, plus all report experiments (Questions
  3–11).
- `requirements.txt` — dependencies.

## Setup
```bash
pip install -r requirements.txt
jupyter lab
```
Open `CS6220_DM_Homework02_Rutuja.ipynb` and run all cells.

## Notes
All cells are pre-run with outputs saved. The full write-up (pseudocode,
tables, and discussion) is in the accompanying report.
